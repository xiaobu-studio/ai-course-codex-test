# AI 工具實戰課程介紹頁

這是一個以純 HTML、CSS 與 JavaScript 製作的單頁課程網站，介紹「AI 工具實戰課程」的特色、課程內容、學員評價、價格方案與常見問題。

網站包含響應式版面、深色模式、課程內容展開、報名表單驗證、FAQ 展開收合，以及手機版漢堡選單等互動功能。

## 檔案結構

```text
ai-tools-course/
├─ index.html   # 網站內容與頁面結構
├─ style.css    # 視覺樣式與響應式版面
├─ script.js    # 頁面互動功能
└─ README.md    # 專案說明
```

## 開啟方式

不需要安裝套件，直接以瀏覽器開啟 `index.html` 即可使用。

也可以在專案資料夾啟動任意靜態網站伺服器，再透過本機網址預覽。

## 技術

- HTML5
- CSS3
- Vanilla JavaScript
- GitHub Pages
